# NAQT Question Format Specification

## Tossup Format

### Structure
A tossup is a single question read aloud by a moderator. Players may buzz in at any point to answer. The question is a series of declarative statements (NOT interrogative), ending with "For ten points, name/identify..."

### Pyramidal Difficulty
Clues are ordered hardest to easiest. This is the defining feature of quality quiz bowl writing.

**Power mark**: The boundary between the power zone (15 points) and regular zone (10 points). In NAQT IS sets, the power mark is after approximately the first sentence or 25% of the tossup.

### Character Limits
- High School IS (Introductory Series): 260-291 characters
- High School IS-A: 375-425 characters (this is what MHS uses)
- College: Up to 500+ characters

### Clue Construction

**Lead-in (Clue 1 — Power zone)**:
- Should be answerable only by someone with deep knowledge
- Never name the answer or its category
- Never start with "This" — it signals answer type
- Good: "The Res Gestae Divi Augusti catalogs this ruler's achievements including adding Egypt as a province."
- Bad: "This emperor's autobiography lists his achievements." (too easy for a lead-in)

**Middle clues (Clues 2-3)**:
- Progressively easier
- Each clue should be independently useful (not dependent on hearing previous clues)
- Use different categories of knowledge: one biographical, one about achievements, one about context

**Giveaway (Final clue)**:
- Should be answerable by most prepared players
- Ends with "For ten points, name..." or "For ten points, identify..."
- Good: "For ten points, name this Macedonian king whose conquests spread Greek culture across a vast territory."
- Bad: "For ten points, who was Alexander the Great?" (too direct, and uses question format)

### Answer Lines

**Primary answer**: The most common/expected form
**Acceptable answers**: Reasonable alternatives in brackets
- Example: `Augustus [accept Caesar Augustus, Octavian, Gaius Octavius]`

Answer acceptance rules:
- Accept common English and original language forms
- Accept reasonable abbreviations for long titles
- Prompt on partial answers (e.g., if answer is "Julius Caesar" and player says just "Caesar," moderator prompts: "Can you be more specific?")
- Accept surname alone for unambiguous figures (e.g., "Hammurabi")

### What NOT to Do in Tossups
- Don't write "fun fact" style questions with no pyramidal structure
- Don't start multiple clues with the same word/phrase
- Don't include value judgments ("the greatest," "the most important")
- Don't write two tossups whose answer is the same entity
- Don't require players to do math or logic puzzles
- Don't reference other questions in the same packet

## Bonus Format

### Structure
A bonus is asked to the team that correctly answers the preceding tossup. It has:
1. A **lead-in** connecting to the tossup answer (1 sentence)
2. Three **parts**, each worth 10 points

### Difficulty Targets
- Part 1 (Easy): ~90% conversion. Textbook-level fact.
- Part 2 (Medium): ~50% conversion. Requires solid study.
- Part 3 (Hard): ~15% conversion. Deep knowledge, obscure.

### Bonus Rules
- Parts should be related to each other and to the tossup topic
- Each part is a self-contained question (not building on previous parts)
- Parts can be ordered easy-medium-hard OR mixed
- Parts should test different aspects of the topic (not three questions about the same sub-detail)
- Bonus answers can be shorter and more direct than tossup answers

## Scoring Summary

| Action | Points |
|--------|--------|
| Correct buzz in power zone | +15 |
| Correct buzz after power mark | +10 |
| Incorrect buzz (neg) | -5 |
| Bonus part correct | +10 |
| Bonus part incorrect | 0 |
| Maximum per tossup cycle | 45 |

## Match Format (High School)
- Two 9-minute halves
- 24 tossups + 24 bonuses per match
- 4 players per team
- Buzzer lockout system
- Only one player may answer per tossup
